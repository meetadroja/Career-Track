# Career Track 🎓

Career Track is a web-based career guidance platform designed to help students explore different career opportunities, understand educational pathways, and plan their future careers. It provides information about career fields, education, certifications, internships, jobs, and leadership opportunities in one place.

The platform is designed with a simple and user-friendly interface to make career exploration easier for students.

## 🚀 Features

- **User Authentication** – Login, signup, and password reset functionality.
- **Career Exploration** – Explore different career fields based on your interests.
- **Engineering** – Explore engineering degrees, colleges, certifications, internships, jobs, and leadership opportunities.
- **Medical** – Discover medical education, colleges, internships, licensing, and career opportunities.
- **IT & Technology** – Learn about IT degrees, certifications, internships, job roles, and career growth.
- **Design** – Explore design education, certifications, internships, and creative career opportunities.
- **Government Jobs** – Discover government career paths, exam preparation, training, and job opportunities.
- **Business** – Explore business education, business schools, and career opportunities.
- **Responsive Design** – User-friendly interface across different screen sizes.

## 💻 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/meetadroja/Career-Track.git
```

### 2. Open the project folder

```bash
cd Career-Track
```

### 3. Run the project

For the career guidance website, you can open `web_programming/index.html` in your browser.

For PHP login/signup functionality:

1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Configure the database connection in `Login_Signing/db.php`.
5. Open the project in your browser using localhost.
